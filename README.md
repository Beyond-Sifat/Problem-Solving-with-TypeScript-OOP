# TypeScript & OOP Assignment

## Overview

This repository contains my solutions for the TypeScript Problem Solving and Object-Oriented Programming assignment.

The assignment focuses on practicing fundamental TypeScript concepts through eight programming problems and two technical blog posts.

## Technologies Used

TypeScript
Object-Oriented Programming (OOP)
TypeScript Generics
Promises and Asynchronous Programming

## Problem Solutions

All eight coding solutions are implemented in a single file:

Optional and default parameters
Union types and type narrowing
Readonly tuples
Generic functions and rest parameters
Interfaces and array filtering
Generics with keyof constraints
Classes, inheritance, and access modifiers
Promises and asynchronous validation

See [solutions.ts](./solutions.ts).
